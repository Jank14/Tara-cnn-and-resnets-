Same picture every time — only the 3×3 kernel changes. An edge kernel lights up wherever brightness changes sharply (the outline of the ears, the eyes, the edge of the face). A blur kernel does the opposite: it averages neighbors together and erases exactly those edges. A trained conv layer's first-layer kernels look almost exactly like these — edge and blob detectors — which is why visualizing a trained network's early filters is such a common sanity check.
