Reading einsum — Watch the Shared Dimension Collapse

TARA · Week 2 · Section 2 — same three rules explain every einsum you'll meet all course
Contract — in BOTH inputs, NOT in output → summed away Keep — in only ONE input + output → kept as-is Batch — in BOTH inputs AND output → matched per-position
The reading procedure, every time: find letters shared between inputs. If a shared letter is absent from the output → summed over (contracted). If a shared letter is in the output → batch dimension. Any letter in only one input → kept.
