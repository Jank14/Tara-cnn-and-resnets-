Two Linear layers back to back compute y = W₂(W₁x) = (W₂W₁)x — algebraically ONE matrix, no matter how many Linear layers you stack. An activation function sits between them and breaks that algebra: you can no longer multiply the two weight matrices together and get an equivalent single layer, because there's a non-linear function in between. That's the entire reason every real network alternates Linear → activation → Linear → activation…
