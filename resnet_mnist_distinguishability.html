Every channel shown is a real convolution + ReLU — Sobel-H / Sobel-V / corner / diagonal kernels, the same family a trained conv layer converges toward — never injected randomness. WITHOUT skip, each block only ever sees the PREVIOUS block's already-abstracted channels, never the original pixels, so approximation error compounds and the digit genuinely dissolves into a generic blob. WITH skip, each block still only adds a small correction to whatever the previous block produced — it is NOT a single shortcut from the raw input straight to the output. But because every block only ever adds, never overwrites, unrolling the recursion (h₁ = x + F₁(x), h₂ = h₁ + F₂(h₁), …) shows the original x is still sitting in there as an exact, untouched additive term under every later block's output — never zeroed out, never multiplied away. That's why the drawing you made is still recognizable this many blocks in.
