out[i] = Σj W[i,j] · x[j]     W ~ Uniform(-1, 1)
Both networks are otherwise IDENTICAL — same depth, same random seed, same number of neurons per layer (in_features = 256). The only difference is whether each weight is scaled by 1/√(in_features) before use. Every output is a sum of 256 random terms — more terms means more randomness stacks up, so without the 1/√N correction, the total variance roughly DOUBLES every layer.
